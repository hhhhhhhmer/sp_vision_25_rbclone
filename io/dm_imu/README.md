# DM IMU

## 主要类型和函数

- `IMU_Receive_Frame`：描述加速度、角速度和欧拉角三段 packed 串口数据。
- `DM_IMU()`：打开串口并启动接收线程。
- `init_serial()`：串口参数是硬编码的 `/dev/ttyACM0`、921600、无流控、20 ms 超时；打开失败会打印警告并直接 `exit(0)`（不是抛异常）。
- `get_imu_data_thread()`：持续读取协议帧、解析姿态并压入时间队列。
- `imu_at(timestamp)`：在查询时刻前后的姿态间做四元数 SLERP。

## 原理

接收线程把 IMU 欧拉角转换成四元数，并与本机单调时钟时间戳一起保存。图像处理线程按曝光时刻查询姿态，从而补偿串口接收与相机采集之间的时间差。该模块独立于云台内置 IMU，只有使用外置达妙 IMU 的程序才需要它。

注意端口名不可配置，且 `DM_IMU` 的对象生命周期内只打开一次串口，没有掉线重连（云台 `Gimbal` 才有 `reconnect()`）。
